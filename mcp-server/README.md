# MCP Server（开发副本）

**全局安装位置（生产使用）：**

```
~/.cursor/mcp-servers/iume-atelier-blog/
```

本目录为 iume-atelier 项目内的开发副本。修改后同步到全局：

```powershell
& "$env:USERPROFILE\.cursor\scripts\install-iume-atelier-blog-mcp.ps1"
```

全局 Skill：`~/.cursor/skills/iume-atelier-publish/SKILL.md`

任意 Cursor 项目均可通过 MCP `iume-atelier` 发布文章，无需在本项目安装依赖。
